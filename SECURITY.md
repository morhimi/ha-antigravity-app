# Security Policy

## Supported Versions

Only the latest release line of the **Antigravity CLI Home Assistant App** receives security updates and bug fixes:

| Version | Supported          |
| :------ | :----------------- |
| 1.3.x   | :white_check_mark: |
| < 1.3   | :x:                |

---

## Reporting a Vulnerability

We take the security of this project and your Home Assistant environment seriously. If you discover a security vulnerability, please do **NOT** open a public issue or discuss it publicly.

Instead, report it privately through GitHub:

1. Navigate to the [Security Advisories tab](https://github.com/morhimi/ha-antigravity-app/security/advisories/new) of this repository.
2. Click **Report a vulnerability**.
3. Provide a detailed summary of the vulnerability, steps to reproduce, and any potential impact.

### What to Expect

- **Acknowledgment**: You will receive an initial response acknowledging your report within 48 hours.
- **Assessment**: We will investigate and confirm the issue, working with you on remediation if needed.
- **Fix & Disclosure**: Once resolved, a patch release and coordinated security advisory will be published with attribution.
